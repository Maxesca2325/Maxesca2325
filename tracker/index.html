L'historique démarre au lancement, avec le premier vrai pronostic. On n'affiche aucun chiffre tant qu'il n'y a pas de vrais résultats.

Comment lire ces chiffres

Réussite : part des pronostics gagnés parmi ceux réglés (les matchs reportés ou annulés ne comptent pas).

Attendu : nombre de pronostics qu'on aurait dû gagner si les probabilités annoncées étaient parfaitement justes. Si on gagne beaucoup moins que l'attendu, le modèle est trop optimiste.

Empreinte : avant le coup d'envoi, le pronostic est scellé. On publie seulement son empreinte (SHA-256). Après le match, le pronostic et le code de vérification apparaissent : chacun peut recalculer l'empreinte et vérifier qu'on n'a rien changé.

Score de Brier : l'écart moyen entre la probabilité annoncée et le résultat. Plus il est bas, mieux le modèle est calibré.
